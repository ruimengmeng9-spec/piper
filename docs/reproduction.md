# 复现与版本对应

## 两套源码的角色

`runtime/` 保存项目本地训练入口及其直接依赖。`experiments/expanded24/source/` 保存当前冻结策略数据与价值网络实验的独立科学源码快照。后者的 `source_manifest.json` 包含 65 个文件的 SHA-256，所有文件均保持原始字节。

原始共享源码压缩包 SHA-256：

`c97fc79e1043cb350a7c3a3301870f98db37aed3ee303bded05919a871c2aa75`

每个实验必须使用对应阶段的源码、资产、模型和配置。不能用最新环境文件与旧检查点随意组合后宣称复现了原指标。

## 当前仍缺少的复现资料

本次公开仓库尚不含原始轨迹、模型权重、完整任务参数和比赛 CAD。它是代码与汇总公开版，不能独立复现训练数值。根据资料所有者的选择，原始轨迹、模型权重与比赛 CAD 保持非公开，不发布为 GitHub 或 Release 附件。

历史机器人资源准备入口为 `runtime/download_model.py`。对应 URDF、网格和 Isaac Lab 环境需要额外准备；本仓库没有将运行时依赖重新打包。

## 校验

在仓库根目录运行 `python tools/verify_export.py`，检查本次导出清单与 65 个科学源码文件。该校验仅验证仓库字节完整性，不运行仿真，也不替代策略评估。

服务器侧脚本保留其原工作目录与实验布局，供追溯算法和门槛使用。复现前需阅读并配置真实路径，不能在其他机器上直接执行历史清理、容器或协调任务。
