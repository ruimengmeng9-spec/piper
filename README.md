# Piper 灵巧操作与插入策略仿真

本项目研究 Piper 六轴机械臂在比赛装配场景中的对准、插入、接触后退出和重新对准。实验使用上传的挑战杯 STEP 装配建立场景，当前为左臂运动、右臂固定，插销预先固定在夹爪中。

**截至 2026-10-20：合格插入策略已保留；新一阶段正在为接触恢复任务采集价值网络数据，尚未更新动作策略。所有成绩均来自仿真。**

## 进展

| 阶段 | 状态 |
| --- | --- |
| 仿真环境与 STEP 场景接入 | 已完成 |
| 插入策略、控制扰动、质量与夹持位置评估 | 已建立合格基线 |
| 接触退出、重新对准、重试的价值网络泛化 | 进行中 |
| 物体真实抓取、D435 视觉、双臂协作、实机验证 | 尚未完成 |

已保留的合格版本在四组独立测试中分别成功 508/512、511/512、511/512、510/512，四组超过 100 N 的次数均为 0。条件和校验标识见 [基线结果](reports/qualified_baseline.json)。这些结果不能直接代表新压力场景的成功率。

当前 expanded24 计划采集 24 组、每组 128 回合，共 3072 回合。快照中实际完成 1280 回合，1152 回合已完成服务器与本地双端验收；另 128 回合已在服务器归档。当前实验尚未进行联合拟合、盲测或 PPO 动作策略更新。详见 [当前进度](reports/current_stage.json)。

- `experiments/expanded24/helpers/`：分批采集、校验和后续联合拟合的服务器侧脚本快照。

## 运行条件

历史实验使用 Isaac Lab 2.3.2、PhysX GPU、PyTorch 与 RSL-RL；资源转换流程适配过 URDF 导入器 2.4.19。服务器实验在 RTX 5090 上运行。仓库不包含 Isaac Sim/Isaac Lab 安装、Docker 镜像或商业运行时。

`runtime/train.py` 的初始默认任务是简化场景。复现比赛场景必须显式设置 `--scene_profile challenge_cup`、对应 CAD 目录及原实验配置。只运行默认入口无法复现合格策略成绩。

代码中的历史服务器绝对路径和容器名属于原实验快照。迁移时需准备自己的工作目录、运行时和数据；不要直接照搬服务器协调脚本执行清理或重启。不同阶段的环境、模型、观测、限幅配置必须成套使用。

```bash
python tools/verify_export.py
```

完整说明见 [复现说明](docs/reproduction.md)；训练内容见 [知识架构](docs/training_architecture.md)；下一步见 [后续计划](docs/roadmap.md)。
